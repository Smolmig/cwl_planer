CWL Planer PWA – GitHub Pages

1. Auf github.com ein neues Repository erstellen, z. B. cwl-planer.
2. Alle Dateien aus diesem ZIP direkt in die Repository-Hauptebene hochladen.
3. Repository > Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, Folder: /(root), Save.
6. Die danach angezeigte github.io-Adresse in Safari öffnen.
7. Safari > Teilen > Zum Home-Bildschirm.

Hinweise:
- Die App speichert Daten lokal auf dem jeweiligen Gerät.
- In der App kannst du ein JSON-Backup exportieren/importieren.
- Nach dem ersten vollständigen Laden funktioniert sie auch offline.
